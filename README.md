# My First Project 🌱

このプロジェクトはプログラミングを勉強するための練習用リポジトリです。

## このリポジトリについて

- はじめてGitHubを使う練習をしています
- 少しずつ改善していく予定です

## 使い方

1. このページを読む
2. 内容を確認する
3. 改善点があればIssueを作成する
4. プルリクエストで変更を提案する

## 目標

- GitHubの使い方を覚える
- プルリクエストを体験する
- コードレビューを学ぶ
- オープンソースに貢献する
